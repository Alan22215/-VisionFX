## 1. R&D Objective

The objective of this session was to validate the technical feasibility of the VisionFX real-time visual processing engine.

The experiment focused on building the first AI-powered visual processing pipeline capable of:

- Accepting video input
- Capturing live camera input
- Detecting people using AI
- Generating person segmentation masks
- Isolating the detected performer
- Generating an AI-driven outline
- Applying a neon/glow effect
- Measuring processing performance
- Identifying performance bottlenecks
- Testing optimization strategies

The main objective was not to build the final application, but to establish a measurable technical baseline for the future VisionFX engine.
